## Decision

d1 reads every question's option logits with one head matmul (b585b8fb). That changes rounding and makes one question's
logits depend on the others in the request. One GEMM per question with a single read-back keeps the bits and still removes
the host syncs: measure both before choosing.

## Kept on purpose

The scheduler's idle work catches `Exception` (6153c3ea): a non-RuntimeError there used to kill the worker thread and hang
the server. It logs and turns disk writes off. This is a deliberate exception to the narrow-catch rule.
